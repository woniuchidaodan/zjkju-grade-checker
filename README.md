# zjkju-grade-checker
适用于湛江科技学院教务系统智能化成绩查询，支持自动查询、成绩变化推送、数据统计分析等核心功能。

方正教务系统查询脚本（湛江科技学院）

该脚本适用于湛江科技学院教务系统智能化成绩查询，支持自动查询、成绩变化推送、数据统计分析等核心功能。

🚀 核心功能特色

1. 双模式查询，灵活适配需求单次查询：即时获取当前学期/学年成绩，快速查看详细分数自动查询：后台定时监控成绩更新（最小间隔5分钟），无需手动反复查询无头模式：默认静默运行不弹窗，也可手动开启可视化浏览器窗口
2. 智能成绩监控与推送基于MD5哈希算法检测成绩变化，新增/更新成绩即时发现QQ邮箱多通道推送（SSL/TLS双协议+备用服务器），确保通知不丢失成绩变化自动发送详细报告，包含课程分数、学分、绩点等完整信息
3. 全面数据统计分析自动计算总学分、平均学分绩点（GPA）、加权平均分支持等级制成绩（优秀/良好等）自动转换为数值计算过滤补考/重考成绩对绩点的影响，统计结果更精准
4. 稳定可靠的技术实现多URL备用查询机制，适配教务系统页面结构变化支持AJAX和HTML表格双解析模式，数据获取成功率高智能处理浏览器驱动，自动适配不同安装路径完善的错误处理和日志记录，问题排查更高效
5. 人性化使用体验首次使用引导配置，小白也能快速上手配置自动保存，下次启动无需重复输入支持账号信息修改、查询间隔自定义、超时时间调整清晰的终端输出格式，成绩展示一目了然
6. 安全保障本地保存配置信息，不泄露账号密码浏览器自动化特征隐藏，避免被教务系统拦截全程HTTPS加密传输，数据传输更安全


📋使用场景

考试后实时监控成绩发布，第一时间获取分数自动记录成绩变化，跟踪学分和绩点达标情况无需手动登录教务系统，节省查询时间多人共用一台电脑时，快速切换账号查询

🛠️技术栈

核心框架：Python3.12

网页自动化：Selenium

网络请求：Requests

邮件推送：SMTP协议（多服务器冗余）

数据处理：JSON+正则表达式
